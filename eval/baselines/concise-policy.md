# Engineering policy baseline

- Clarify material unknowns before committing to architecture or UX.
- Prefer the smallest coherent implementation that satisfies the request.
- Validate inputs and authorization at trust boundaries.
- Use additive, backwards-compatible data changes for rolling deploys.
- Add focused automated tests for critical behavior and failure paths.
- Run the product, tests, and build before claiming completion.
- Report remaining uncertainty explicitly.
