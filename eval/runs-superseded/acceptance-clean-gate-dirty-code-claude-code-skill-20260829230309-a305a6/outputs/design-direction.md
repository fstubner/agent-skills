# Design direction

## Interview
Asked the ward sister: notes are written standing up, in gloves, in under a
minute, on a shared tablet in a bright corridor. Nothing decorative; the
last shift's notes must be readable at arm's length.

## Direction
Calm and high-contrast. One accent (#0B6E4F) on a near-white surface
(#FAFAF7), text #14302A. Type no smaller than 16px, tap targets 48px, and
the note list ordered most recent first.
