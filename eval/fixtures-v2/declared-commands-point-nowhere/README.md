# Ledger API

Double-entry ledger read API.

```bash
npm install
npm start        # serves on PORT, default 3000
npm test
npm run build
```

The service itself is in `src/server.js` and works — `createApp()` is imported
directly by the one place that consumes it today.

This repository was generated from a template last week. Nobody has run any of
the commands above.
