# Clinic portal

Booking and records front end for a group of small clinics. Built over about
three years by four people, none of whom are still on the team.

Styling grew as the app grew: `styles/base.css` came first, `components.css`
was added when the component folder appeared, and `utilities.css` was added
by whoever needed a one-off. `src/theme.js` arrived with the appointment
calendar, which needed colours computed at runtime for the density shading.

There is no design system. Nobody has audited the styling.
