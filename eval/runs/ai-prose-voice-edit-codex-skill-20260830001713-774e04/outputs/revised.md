# The Friday deploy

This tiny script is our team’s deploy check.

I wrote the first version after the pager woke me at 02:13 last Friday.
It is 43 lines, including the rude comment about YAML.
Mara calls the deploy button “the big red nope button.”

The tool shortens the check and changes the workflow.
Research suggests that automation supports engineering excellence.
On Tuesday, the check took 11 minutes; after the change, it took 74 seconds.
