# Shift notes

## Purpose
Nurses on a ward write short handover notes at the end of a shift so the
next shift can read them.

## Users
Ward nurses. Everyone signs in with a staff account.

## Success
A nurse can write a note in under a minute and read the previous shift's
notes for their own ward.

## MVP scope
Write a note, list notes for my ward, sign out. Not in scope: editing a
posted note, attachments, cross-ward search.

## Constraints
Runs on a ward tablet. Node 18+, no external services.
