# Swim session booking

## Provenance
reconstructed-from-code

## Purpose
Parents book children onto swimming lesson sessions at the leisure centre
without phoning reception.

## Users
Parents with one or more children registered at the centre. Reception staff
use the same tool to book on a parent's behalf.

## Success
A parent can book a child onto an available session and see that the booking
was taken.

## MVP scope
List available sessions, book a child onto one, cancel a booking, sign out.
Not in scope: payment, waiting lists, session reminders.

## Constraints
Runs on the centre's reception terminal and on parents' phones. Node 18+, no
external services.
