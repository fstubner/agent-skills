# Canonical secret-pattern list. One extended-regex (ERE) pattern per line;
# lines starting with # are comments. This exact syntax is shared verbatim
# across every consumer — JS RegExp (secret-patterns.cjs), POSIX/GNU/BSD
# `grep -E` (scripts/git-hooks/pre-commit), and PowerShell/.NET regex
# (scripts/git-hooks/pre-commit.ps1) — so there is exactly one place a new
# prefix gets added, not three that can drift.
#
# Anchored, prefix-based patterns ONLY. The v0.4 scanner used
# /sk-[a-zA-Z0-9]{10,}/ with no boundary and BLOCKed projects for containing
# the phrase "task-management". Every pattern here requires a real key
# prefix.
#
# Boundary via (^|[^A-Za-z0-9_-]) instead of \b: POSIX/BSD `grep -E` does
# not support \b (it's a GNU extension), so this suite deliberately does not
# rely on it. This form means "start of line, or the previous character
# isn't part of an identifier" and is understood identically by all three
# engines above. No trailing boundary is needed: every suffix class below
# is a greedy {n,} quantifier, which already stops at the first
# non-matching character — a trailing boundary check there would be
# redundant, not stricter.
(^|[^A-Za-z0-9_-])sk_(live|test)_[A-Za-z0-9]{10,}
(^|[^A-Za-z0-9_-])sk-ant-[A-Za-z0-9_-]{10,}
(^|[^A-Za-z0-9_-])sk-proj-[A-Za-z0-9_-]{10,}
(^|[^A-Za-z0-9_-])AKIA[0-9A-Z]{16}
(^|[^A-Za-z0-9_-])ghp_[A-Za-z0-9]{30,}
(^|[^A-Za-z0-9_-])xox[baprs]-[A-Za-z0-9-]{10,}
