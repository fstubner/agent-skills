Install xtctx as a plugin, set it up per project, or both.

xtctx indexes the transcripts that AI coding agents write on your machine and serves them over MCP.

Transcripts stay on your machine unless a project turns on cloud sync or a remote embedding endpoint.

Search matches keywords by default.

Setup always writes Antigravity's file, because Antigravity has no project-level MCP config.

Releases are manual.

Setup adds a short xtctx section to the file and leaves the rest of the file unchanged.

Setup adds a short xtctx section to the instruction files the agents read, telling them which tools to use.
